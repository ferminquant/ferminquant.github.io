personal-mcp privacy policy

Last updated: October 27, 2026

What this is

personal-mcp is a local application used by Fermin Quant and a small number of personally known users. It allows a personal AI assistant to read Google Sheets that the user explicitly identifies.

Google data accessed

With the user's permission, the application requests the Google OAuth scope https://www.googleapis.com/auth/spreadsheets. Google describes that scope as permission to see, edit, create, and delete all of the user's Google Sheets spreadsheets. The application's current tools only read metadata and cell values, update values in an explicitly requested range, append rows, and set display formats such as percentages and currency. They do not expose creating, deleting, or sharing spreadsheets.

How data is used

Spreadsheet data is read or updated only to answer the user's request inside their personal AI assistant. The data may be sent to the AI model provider configured in that assistant so the model can process the request. That provider's own terms and privacy policy apply to that processing. The data is not used for advertising and is not sold.

Storage

Google OAuth client credentials and refresh tokens are stored locally on the user's own computer. The application does not operate a server that receives or stores Google user data. The AI assistant may keep local session history, including tool results returned by this integration; that history remains on the user's computer and can be deleted by the user.

Sharing

Google user data is not sold, rented, or shared with advertisers. It is shared only with the AI model provider selected by the user, as necessary to answer the user's request, or when required by law.

Retention and deletion

The application does not maintain a separate cloud store of Google user data. Local tokens remain until the user deletes them. The user can revoke the application's Google access at myaccount.google.com/permissions and can delete local token and session files from their computer.

Google API Services User Data Policy

personal-mcp's use of Google user data is intended to comply with the Google API Services User Data Policy, including its Limited Use requirements.

Changes

This policy may be updated as the tool changes. The date at the top of this page shows the latest revision.
